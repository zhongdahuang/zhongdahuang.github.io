# Zhongda Huang

- Preliminary commissioning of a prototype solid tank optical CT scanner for 3D radiation dosimetry. *Journal of Physics: Conference Series*, 2023. [doi](https://doi.org/10.1088/1742-6596/2630/1/012036)
