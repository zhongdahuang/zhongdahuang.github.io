# Zhongda Huang

- Iterative Image Reconstruction Methodology in Optical CT Radiochromic Gel Dosimetry. *Journal of Physics: Conference Series*, 2023. [doi](https://doi.org/10.1088/1742-6596/2630/1/012033)
